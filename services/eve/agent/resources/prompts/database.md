# UGC Agent Database Access Guidelines

## Available Database: PostgreSQL

I have access to a PostgreSQL database that stores all assets generated by the UGC agent (images, videos, etc.).

This database is used to answer user questions about:
- What assets were generated
- When they were generated
- For which conversation or user
- What type of asset was created (image/video)
- Where the asset is stored

---

## Database Schema

### Table: ugc_assets
Stores all assets generated by the UGC agent.

**Columns:**

- `id` (uuid / integer, primary key)  
  Unique identifier for each asset

- `conversation_id` (text)  
  Conversation ID that links the asset to a specific chat/session

- `asset_type` (text)  
  Type of asset generated  
  Example values: `image`, `video`, `thumbnail`, `reel`

- `asset_url` (text)  
  Path or URL to the generated asset (local asset folder or CDN)

- `prompt` (text)  
  The prompt or instruction used to generate the asset

- `agent_name` (text)  
  Always `ugc_agent` for this table

- `created_at` (timestamp)  
  When the asset was generated

- `metadata` (jsonb)  
  Extra information like style, avatar used, product name, etc.

---

## Query Guidelines

### When User Asks About Generated Assets

If the user asks:
- “What images were generated by the UGC agent?”
- “Show me assets created in this conversation”
- “What did the UGC agent generate for me?”
- “List all UGC images/videos”

You should **query the `ugc_assets` table**.

---

### Example: Get All Images Generated by UGC Agent

```sql
SELECT asset_url, prompt, created_at
FROM ugc_assets
WHERE agent_name = 'ugc_agent'
  AND asset_type = 'image'
ORDER BY created_at DESC;
